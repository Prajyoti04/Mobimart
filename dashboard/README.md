# MobiMart Dashboard

## Run
1. Install Python 3.10+.
2. In this folder run:
   `pip install -r requirements.txt`
3. Start:
   `streamlit run app.py`

## Dashboard sections
- Simulation stress test
- Optimized allocation
- EOL + markdown decisions
- Store-level predecessor → successor transfers

The dashboard uses CSV extracts generated from the project pipeline and is intentionally self-contained.
